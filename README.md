# Practice lab handbook

> **This is a practice repository, not the lab's real handbook.** It's here so you can learn to fork a repository, make a change on a branch and open a pull request, as in the lab's [Git and GitHub guide](guides/git-and-github.md). The content is only an example. Pull requests may be merged or closed, and the repository is reset from time to time.

## Contributing

Anyone can practise here. Fork this repository, make your change on a branch, and open a pull request.
