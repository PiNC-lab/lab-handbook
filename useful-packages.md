# Useful R packages

Example content for practising pull requests, not an official lab list. To add a package, fork this repository and open a pull request.

## Data handling

- **readr**: fast reading of CSV and other text files.
- **dplyr**: filtering, summarising and joining data frames.

## Spatial

- **sf**: vector data such as points, lines and polygons.

## Modelling

- **mgcv**: generalised additive models. Comes with R.
- **lme4**: mixed-effects models.

## Plotting

- **ggplot2**: most of our figures.
